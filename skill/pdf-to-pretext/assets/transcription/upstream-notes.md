# Notes for upstream

Where the skill was silent or wrong while this document was transcribed.  Add an entry
each time something had to be worked out that the skill should have said; not every
decision belongs here.  Write nothing that quotes the document: describe the construct,
or show it with a few lines of your own.

Each entry is one of three kinds, and they go to different places:

- `skill`: the skill lacks it, or says it wrongly.  An issue or pull request for the skill.
- `pretext`: PreTeXt itself misbehaves.  An issue for PreTeXtBook/pretext, with a minimal
  source that shows it.
- `document`: a peculiarity of this one document.  Recorded so that it is not mistaken for
  either of the others; it goes nowhere.
